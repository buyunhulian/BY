# BY框架

BY框架是一个轻量、可扩展的QQ机器人框架，支持接入QQ官方机器人，并提供多语言插件系统，方便开发者使用自己熟悉的语言编写插件。框架内置丰富的群管理与聊天功能，可快速搭建功能强大的QQ机器人。

## ✨ 特性

- **QQ官方机器人接入**  
  支持通过QQ官方机器人开放平台接入，安全合规，稳定可靠。

- **多语言插件支持**  
  插件可使用以下语言编写，满足不同开发者的技术栈：
  - PHP
  - JavaScript / Node.js
  - Python
  - C++
  - 易语言

- **内置管理功能**
  - 聊天：发送群消息、私聊消息
  - 群黑名单：禁止指定群使用机器人
  - 框架黑名单：全局禁止指定用户使用机器人
  - 禁言：对群成员进行禁言
  - 解禁：解除群成员禁言
  - 踢人：将指定成员移出群聊

- **插件热加载**  
  无需重启框架即可加载、卸载插件。

- **事件驱动**  
  支持消息事件、群事件、好友事件等，插件可监听并处理。

- **配置灵活**  
  支持多配置文件、环境变量，方便部署。

## 🚀 快速开始

### 环境要求
- 操作系统：Windows
- 运行时：根据插件语言安装对应环境（如 PHP、Node.js、Python 等）
- 网络：可访问QQ官方机器人API
###安装
-用release的exe去安装
